Готовые файлы для импорта в Kerio Connect MailServer:
⬇ Скачать сертификат (.crt Fullchain) 🔑 Скачать приватный ключ (.key RSA)
📦 Скачать весь комплект (.zip + install-kerio.bat) Цепочка CA (chain.crt) Только сертификат (cert-only.crt) Архив PKCS#12 (.pfx) Запрос CSR (.csr)
  1. Откройте веб-консоль Kerio Connect Administration (https://<IP-сервера>:4040/admin).
  2. Перейдите в меню Конфигурация (Configuration) → Сертификаты SSL (SSL Certificates).
  3. Нажмите кнопку Импорт (Import) → Импортировать новый сертификат... (Import New Certificate...).
  4. В первом поле Сертификат (Certificate) выберите скачанный файл server.crt (он уже содержит ваш сертификат + промежуточный сертификат Let's Encrypt).
  5. Во втором поле Приватный ключ (Private key) выберите файл server.key (незашифрованный RSA ключ).
  6. Выделите добавленный сертификат в таблице и нажмите Использовать (Set as Active) — готово!

💡 Важные особенности SSL в Kerio Connect

          
    
            
  • Почему нужен Fullchain (server.crt): почтовые клиенты Outlook, Android и iOS требуют, чтобы сервер отдавал не только сертификат домена, но и промежуточный корневой сертификат Let's Encrypt (R10/R11/E5). Наш файл server.crt уже объединяет их в правильном порядке.
    • 
            
  • Почему RSA 2048 Traditional PKCS#1 (BEGIN RSA PRIVATE KEY): встроенный SSL-движок Kerio Connect гарантированно читает незашифрованные ключи RSA 2048/4096 бит на всех версиях Kerio (8.x, 9.x, 10.x).
    • 
            
  • Проверяемые почтовые протоколы после установки: HTTPS WebMail (443), SMTPS (465), SMTP STARTTLS (25 / 587), IMAPS (993), POP3S (995).
