# Подключение к Jira (Android 1.10.4)

## Что изменилось

В версиях до 1.10.4 native bridge не имел `testConnection`/`fetchTickets`:
сообщение «метод не реализован» не означало сетевую ошибку. Теперь добавлен
нативный read-only клиент Jira REST v2. WebView по-прежнему не загружает сеть:
HTTPS запросы выполняются в Java на отдельном executor, системные TLS checks включены.

## Использование

1. Установить новый подписанный APK. Из-за временного debug-ключа может потребоваться
   удалить старую версию: перед этим экспортировать нужные локальные данные.
2. Ввести полный HTTPS URL, например `https://h.csl.by`. Если Jira работает под
   `/jira`, указать `https://host/jira`, а не ссылку на dashboard/страницу login.
3. Указать Jira username и пароль (если Basic Auth разрешен на сервере).
   Для поддерживающих такой режим серверов можно использовать API token вместо
   пароля. **PAT с Bearer, OAuth и браузерный SSO сейчас не реализованы.**
4. В настройках нажать «Тест». Результат проверки остается под кнопками.
   Тест не заменяет текущую активную учетную запись; для применения нажать
   «Сохранить». После сохранения загружаются доступные пользователю заявки.
5. «Онлайн» появляется только после подтвержденного `/rest/api/2/myself` и
   успешного получения списка. Пароль живет только в памяти до выхода/закрытия;
   при следующем запуске ввести заново. Никаких паролей в логи/документацию не писать.

## Поддержка и ограничения

Первичная цель — Jira Server/Data Center с HTTPS, Basic Auth и REST v2:
`GET /rest/api/2/myself`, `GET /rest/api/2/search`.
Запросы search идут постранично по 100, с учетом фактического размера страницы,
до указанного сервером total; защита 5000 записей. При ошибке/превышении лимита
частичный список не применяется. Существующий снимок сохраняется при ошибке сети.
Успешный пустой ответ удаляет старые серверные записи, но сохраняет LOCAL-черновики.
Обновление при входе/сохранении настроек/кнопке refresh и каждые 5 минут, пока UI
вошел в аккаунт. Фонового Android-сервиса и гарантированного polling в фоне нет.

Создание заявок, статусы и комментарии **пока локальные**, REST write не реализован.
Jira Cloud с новым search API, SSO, CAPTCHA, Bearer PAT могут требовать отдельной
реализации — не гарантировать работу на любой конфигурации Jira.

## Диагностика

- **401**: неверные данные, Basic Auth отключен, CAPTCHA; обычный успешный вход
  в браузере не доказывает, что API принимает Basic Auth.
- **403**: права, CAPTCHA/политика сервера/прокси.
- **3xx / HTML вместо JSON**: SSO или неверный URL; redirects намеренно не
  выполняются, чтобы не передавать Authorization другому адресу.
- **404**: неверный context path или REST v2 отсутствует.
- **410**: endpoint снят с поддержки (в частности некоторые Jira Cloud search).
- **429**: rate limit; повторить позже.
- **TLS**: проверить цепочку сертификата сервера, дату телефона, корпоративную
  политику сертификатов. Не отключать проверку сертификата ради подключения.
- **DNS/timeout**: сеть, VPN, доступность сервера с телефона.

В sandbox разрешены только отдельные внешние хосты, `h.csl.by` не входит в них.
Реальный сервер/учетные данные владельца здесь не проверялись. Следующий тест —
на телефоне; при ошибке передать только точный текст/HTTP код, **не пароль**.

## Архитектура / тесты

- `JiraClient.java`: read-only transport, фиксированные ресурсы, HTTPS URL validation,
  15/20-секундные timeouts, запрет redirects, JSON content type, 4 MiB response cap.
- `MainActivity`: credentials in-memory, native bridge, pagination, stale-session
  callback guard, очистка credentials на logout/destroy. Старый запрос может завершаться
  до network timeout, но его результат не применяется к новому аккаунту.
- Callback args сериализуются JSONArray → JSON string → JSON.parse в JS; ответы
  сервера не конкатенируются как исполняемый JavaScript.
- `bash scripts/test-java.sh`: pure JVM tests с fake HTTP connections, без Jira.
- `node --test tests/*.test.cjs`: UI callbacks, snapshot, ADF-to-text, test-vs-save и
  предыдущие security/publication regressions. Это не Android/Jira integration tests.
